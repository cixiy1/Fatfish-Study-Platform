# 提交包说明

打包命名：`作品名+队名+版本号+联系方式.zip`，例：`智学路径+星火队+v1.0+13800000000.zip`

| 目录 | 放什么 | 硬性要求 |
|---|---|---|
| `ppt/` | 方案介绍 PPT，另存一份 PDF | 场景痛点、架构图、六模块映射、码道应用、创新点、后续规划 |
| `project/` | 完整工程源码 | 解压后 `npm install && npm run dev` 能跑起来 |
| `video/` | 演示视频（≤3 分钟）或在线链接 | 开头 15 秒内出现核心效果 |
| `codearts-proof/` | 码道使用痕迹，按 `YYYY-MM-DD/` 归档 | 每天 ≥3 张，覆盖需求拆解 / 代码生成 / 排错 / 测试 / 文档 |
| `readme/` | 作品说明文档 | 环境依赖、启动步骤、测试账号、开源组件与协议、码道应用总结 |

## 截图命名

`<序号>-<环节>-<说明>.png`，环节取值：`需求` / `生成` / `排错` / `测试` / `文档`。

示例：`01-需求-六大模块拆解与表结构.png`、`02-生成-skills表与种子数据.png`

## 纪律

- 截图当场存，事后补不出来
- 每张截图要能看出是本项目（含项目名或文件路径）
- 涉及密钥、手机号的截图先打码

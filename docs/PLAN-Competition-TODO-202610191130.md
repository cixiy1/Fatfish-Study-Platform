## 3. 范围收敛：5 天只做一条闭环主线

赛题要求六大模块，6 天全做必然全浅。**只把一条主链做深，其余做骨架页 + 接口占位。**

| 赛题六大模块 | 本轮做法 | 落点 |
|---|---|---|
| 用户感知（三维画像） | **做深** | 测评问卷 → 知识基础/性格特质/职业目标 |
| 职业规划 | **做深（轻量）** | 岗位库 + 岗位技能图谱 + 差距分析 |
| 智能导学 | **做深** | 技能点排序 + 路径生成 + 今日任务 |
| 知识答疑 | **做深** | 知识库 RAG 问答，带引用来源 |
| 学习评估 | **做深（轻量）** | 阶段测评 → 掌握度更新 |
| 动态迭代 | **做深（关键差异点）** | 掌握度变化 → 路径自动重排 |
| 多智能体协同 | 骨架 + 4 个 Agent | 画像 / 规划 / 答疑 / 评估 |
| 专业知识图谱 + 岗位技能图谱 | 简化实现 | JSON 技能树（有依赖关系即可，不引图数据库） |

**主线用户旅程（演示脚本就是它）**

```
注册登录 → 10 题诊断测评 → 生成三维画像 → 选目标岗位
→ 看岗位技能图谱与差距 → 生成学习路径 → 学今日技能点
→ 随时提问（RAG 带出处）→ 阶段测评 → 掌握度更新 → 路径自动重排
```

**明确不做（写进 PPT 的"后续规划"更划算）**

- 真图数据库 / Neo4j
- 视频课程、直播、支付、社交
- 移动端 App（响应式 Web 足够）
- 复杂权限体系（复用现有 `useAuthSession` 够了）

## 4. 技术方案清单

### 4.1 技术选型（沿用现状，不换栈）

| 层 | 选型 | 说明 |
|---|---|---|
| 前端/后端 | Nuxt 4 + Nitro | 已有，SSR 一把梭 |
| UI | `@nuxt/ui` v4 + Tailwind | 已有，`primary: teal` |
| 内容/知识库 | `@nuxt/content` | 已有，知识点写成 Markdown |
| 数据 | SQLite（`better-sqlite3` 已装） | 用户、测评、路径、会话 |
| 大模型 | 华为云 MaaS（OpenAI 兼容） | 无 key 时走 mock 分支，保证可演示 |
| 图谱可视化 | 自绘 SVG + 轻量布局 | 不引重型图库，减少翻车面 |

### 4.2 数据模型（先定表，再写页面）

- [ ] `users`：id / account / name / created_at
- [ ] `profiles`：user_id / knowledge_level / personality / career_goal / updated_at
- [ ] `jobs`：id / title / description / skill_ids
- [ ] `skills`：id / name / level / prerequisites（JSON 数组）
- [ ] `assessments`：id / user_id / type（diagnostic|stage）/ score / detail（JSON）
- [ ] `paths`：id / user_id / job_id / nodes（JSON：skill_id + 状态 + 预估时长）
- [ ] `mastery`：user_id / skill_id / score / updated_at
- [ ] `chat_logs`：id / user_id / skill_id / question / answer / citations

### 4.3 服务端接口（Nitro，全部 `server/api/`）

- [ ] `POST /api/profile/assess` — 提交测评，产出三维画像
- [ ] `GET  /api/jobs` — 岗位列表
- [ ] `GET  /api/skills/graph?jobId=` — 岗位技能图谱（节点 + 依赖边）
- [ ] `POST /api/path/generate` — 依据画像 + 岗位差距生成路径
- [ ] `GET  /api/path/today` — 今日任务
- [ ] `POST /api/qa` — RAG 答疑，返回答案 + 引用片段
- [ ] `POST /api/mastery` — 提交阶段测评，更新掌握度
- [ ] `POST /api/path/replan` — 依掌握度重排路径（动态迭代的落地点）

### 4.4 页面清单

- [ ] `/` 首页：价值主张 + 入口（替换现有 Index 页）
- [ ] `/onboarding` 诊断测评（10 题，进度条）
- [ ] `/profile` 三维画像展示
- [ ] `/jobs` 岗位选择 + 能力差距
- [ ] `/skills/[id]` 技能图谱（SVG）
- [ ] `/path` 学习路径 + 今日任务
- [ ] `/learn/[skillId]` 知识点正文 + 侧边问答
- [ ] `/assessment` 阶段测评 + 结果页
- [x] `/login`、`/account` 已有，复用

### 4.5 多智能体编排

- [ ] `server/utils/agent/` 下四个 Agent：`profiler` / `planner` / `tutor` / `evaluator`
- [ ] 统一入口 `server/utils/agent/index.ts`：按意图路由到对应 Agent，共享上下文（画像 + 掌握度）
- [ ] 每个 Agent 的 system prompt 写进独立 md 文件，便于在 PPT 里展示"Prompt 设计"
